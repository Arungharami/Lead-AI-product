# Lead AI Mobile

AI lead capture assistant mobile app using Flutter, FastAPI, Firebase, and OpenAI.

## Android app identity
- **Project name:** Lead AI Mobile
- **Android package name:** `com.leadai.mobile`

> Note: This repository currently contains the Flutter `lib/` MVP scaffold. If `frontend/android/` is not present yet, generate platform folders first with `flutter create .` inside `/frontend`, then set the applicationId/package to `com.leadai.mobile`.

## Backend (FastAPI: AI chat only)
`/chat` uses OpenAI to guide lead capture and return structured lead fields.

### Run
```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# set OPENAI_API_KEY in .env
uvicorn main:app --reload
```

### Endpoints
- `GET /`
- `POST /chat`

## Frontend (Flutter + Firebase)
```bash
cd frontend
flutter pub get
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000
```

### Firebase setup
1. Create Firebase project.
2. Enable **Authentication > Sign-in method > Email/Password**.
3. Enable **Firestore Database** and choose **Start in test mode** for MVP setup.
4. Add Android app in Firebase with package name `com.leadai.mobile` and download `google-services.json`.
5. Put `google-services.json` in `frontend/android/app/`.
6. Add Firebase config files generated by `flutterfire configure` if used.
7. Never commit Firebase private keys or service account secrets.

### Firestore lead schema (per authenticated user)
Each lead saved from mobile app stores:
- `name`
- `phone`
- `email`
- `need`
- `status`
- `createdAt`
- `userId`

## Mobile testing (Android emulator)
1. Start backend: `uvicorn main:app --reload`
2. Run app on emulator.
3. Sign up / login with Firebase email+password.
4. Use AI Chat and tap **Save Lead** when detected.
5. Open Leads tab to verify user-scoped Firestore leads.
